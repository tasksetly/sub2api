Tasksetly Quickstart

五分钟完成第一次 API 调用

一个 API Key 接入已开放的 AI 模型，并在控制台集中查看调用、费用和配额。

注册并创建 API Key

第一步：创建 API Key

  1. 注册并完成邮箱验证。
  2. 进入控制台的 API Key 页面，创建一个新 Key。
  3. 按用途分别创建开发、测试和生产 Key，不要在前端代码或公开仓库中暴露密钥。

第二步：复制客户端配置

在 API Key 列表中点击“使用”，选择你的平台和客户端。控制台会生成对应的 Claude Code、Codex、Gemini CLI 或 OpenCode 配置。

接口地址使用 https://ai.tasksetly.com。模型名称和可用范围以控制台实时显示为准。

第三步：发送最小测试请求

Anthropic Messages 兼容接口：

curl https://ai.tasksetly.com/v1/messages \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "MODEL_ID_FROM_CONSOLE",
    "max_tokens": 64,
    "messages": [{"role": "user", "content": "Reply with OK"}]
  }'

OpenAI Chat Completions 兼容接口：

curl https://ai.tasksetly.com/v1/chat/completions \
  -H "content-type: application/json" \
  -H "authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "MODEL_ID_FROM_CONSOLE",
    "messages": [{"role": "user", "content": "Reply with OK"}]
  }'

常见错误

  • 401：确认 API Key 完整、请求头格式正确。
  • 403：确认 Key、分组或模型访问范围允许本次调用。
  • 429：检查余额、配额、并发和速率限制。
  • 模型不可用：回到控制台复制实时模型 ID，不要凭记忆填写。
  • 流式请求中断：先关闭流式输出完成最小请求，再检查本地代理和网络。

完成标准

收到成功响应后，返回控制台查看调用明细和费用记录。能同时看到成功响应与用量记录，才算完成首次接入。
