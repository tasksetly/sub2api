# 基于开源项目部署了一个 Codex CLI API 服务，想找人帮我跑一遍

大家好，这里是 Tasksetly 的线上服务介绍。底层项目是开源的，这个帖子主要介绍目前部署在官网上的服务，顺便找一些真实用户帮忙跑一遍流程。

开源项目本身解决的是 API 网关、Key 管理和用量计费这些基础问题。线上服务则把这些能力部署起来，先围绕 Codex CLI 做一条比较短的接入路径。真正麻烦的地方往往不是让工具跑起来，而是换环境、查余额和排查失败请求时要反复翻配置。

目前首期只做一件事：让中国用户比较容易地把 Codex CLI 接到一个按量计费的 API 入口上。

官网：<https://ai.tasksetly.com>

现在的规则比较简单：

- 余额按量付费；
- 充值 1 CNY，折算 1 USD 余额；
- Token 消耗从模型基准价格的 0.1 倍起；
- 当前支持 GPT 5.4、GPT 5.6 及以上版本，实际可用模型以控制台显示为准；
- 注册并完成邮箱验证后，可以在站内提交工单申请 3 USD 体验兑换码；
- 体验码需要人工发放，工单会在 24 小时内处理。

这里不写“全网最低价”或者“永不出问题”。中转服务实际会遇到上游调整、模型名变化、网络波动这些事情，当前更重要的是把配置、计费和问题反馈这几个环节做顺。

如果你最近正在用 Codex CLI，欢迎帮忙试一下下面几件事：

1. 从注册到创建 API Key 是否容易理解；
2. 按页面说明配置后，能不能完成第一次真实调用；
3. 余额和 Token 消耗是否看得懂；
4. 如果调用失败，页面上的提示够不够用；
5. 工单申请体验码的流程有没有让人困惑的地方。

比起一句“挺好用”，更希望收到具体反馈，比如“在哪一步找不到按钮”“这个模型名报错”“扣费明细看不懂”。这些反馈可以直接用于修改页面和文档。

如果有人愿意试，注册后在站内提交工单就行。也欢迎直接在评论里指出页面、计费或配置上的问题。这个项目现在还在早期，先把真实使用的人照顾好，比堆一堆宣传词重要。
