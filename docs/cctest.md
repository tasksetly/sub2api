# CCTest 官方检测接入

本功能调用 [cctest.ai 官方 API](https://cctest.ai/docs)：`POST /api/v1/check` 创建任务，`GET /api/v1/check/:taskId` 查询结果。集成依据为 2026-11-15 获取的公开文档；使用 `provider=claude`、`concurrency=1`，可选 `checkTokenUsage`。评分直接来自 CCTest，不复制其黑盒题目、不自行计算总分。

## 启用

1. 部署包含迁移 `267_cctest.sql` 的版本。迁移由项目现有迁移流程管理。
2. 配置固定的 `TOTP_ENCRYPTION_KEY`，供项目已有 `SecretEncryptor` 加密 CCTest 密钥和任务凭证；多实例须保持一致。
3. 在管理端侧栏打开 **CCTest 检测**（`/admin/cctest`），填写购买了检测次数的 `cct-` 服务密钥，以及本站可被 CCTest 访问的公网 HTTPS 基址。
4. 开启 CCTest；如需开放给用户，再开启“开放用户付费测试”。反向代理需要将 `/cctest/relay/v1/messages` 转发到后端，支持 SSE，并允许最多 3 分钟的检测响应。不要将该路径回退成前端 HTML。
5. 在账号列表勾选最多 20 个 Claude 账号，点击 **CCTest 检测**，选择共同模型或手动输入模型 ID，确认费用后提交。后台校验全部账号及模型，任一不符合则整批拒绝。

普通用户访问 `/cctest`，选择自己的有效 API Key、Claude 模型并确认费用后发起检测。用户只能查看和停止自己的检测；管理员列表只包含账号检测，不向普通用户暴露账号信息、站点服务密钥或其他用户记录。

## 费用与请求路径

- 每个检测任务消耗 **1 次站点的 CCTest 额度**。本站不额外向用户收取这项次数费用。价格、额度有效期以 CCTest 当前规则为准。
- 用户的每次模型调用都进入原有 API Key 鉴权、IP 限制、模型白名单、分组映射、路由、并发、配额和计费流程，从本人余额或套餐额度结算，正常产生使用记录。不会因测试失败或取消而抹除已发生的模型用量。
- 用户测的是其 API Key 所属分组的服务；分组可将同一检测的不同请求分配到不同账号，不代表某个固定上游。管理员测试固定到指定账号，复用 `GatewayService.Forward`，不会切换账号或扣某个普通用户余额，上游仍会产生用量。
- CCTest 返回的用量审计成本比是它的测算，不是本站实际扣费金额。实际扣费以本站使用记录为准。
- CCTest 得到的是限时测试凭证，不是真实上游密钥或用户 API Key。本站接收回调后校验凭证、模型、有效期、任务状态与请求上限，再按账号转发或替换为用户的真实 Key 进入正常网关。
- CCTest 可访问检测请求和响应。用户确认文字明确说明这种处理。IP 白名单仍生效：若 Key 仅允许用户本机 IP，来自 CCTest 的请求会被正常拒绝。

## 运行边界

- 任务和结果存储在 PostgreSQL；每实例 2 个轮询 worker，数据库租约避免多个实例重复领取。全局最多 4 个正在检测的任务、100 个活动或排队任务；每位管理员最多 20 个活动任务。
- 普通用户同时最多 1 个任务，滚动 24 小时最多 10 次。计数和任务创建在同一事务中串行校验，失败任务也计入次数，防止无限重试消耗站点额度。
- 每个任务从提交起 30 分钟有效；每个回调最大 4 MiB、输出上限 16,384 tokens；普通检测最多 30 次回调，用量审计最多 60 次。管理员每次上游请求最长 3 分钟，并占用原有账号并发槽。
- 向 CCTest 提交任务时发生网络超时、进程中断或未知响应，不会自动再次 POST，防止重复消耗检测次数。该任务标记失败，必要时先到 CCTest 核对额度再手动重试。已获得任务 ID 的任务在重启后继续查询。
- 停止任务或关闭功能会阻止后续回调。已经在执行的模型请求可能继续完成并产生费用；CCTest 官方文档未提供远程取消接口。
- 终态任务清除加密的任务凭证。结果保存允许的报告字段及审计数值，不保存 CCTest 返回的任意请求体、URL、密钥或原始错误全文。
- 缺失、null 或越界的总分视为无效报告，不显示成零分。模型返回异常、网络故障和取消与“低分”分开呈现。
- 分页历史支持同一批次相同时间戳，使用 `(created_at,id)` 游标。终态检测结果保留 90 天后清除。删除 Claude 账号或 API Key 不会删除已有报告；用户注销会按用户数据策略级联清除报告。页面可以导出当前已加载的结果 JSON。

## 评分含义

总分、各维度分数和 `verdictKey` 均来自 CCTest。报告展示的是通过本站转发后的响应，所以协议适配、模型映射、缓存策略和工具模拟都可能影响结果。页面明确标注这些限制，不能仅凭一个低分直接认定上游掺假。
